# Decisions

## Next.js App Router

Needed server routes for Razorpay secrets, fast UI delivery, and a single TypeScript tree for a hackathon team.

## Deterministic agent for the demo

Judges must see the same Northline sale. A scripted policy engine is auditable. A model can replace `runAgent` later without changing the desk.

## Light-first, cool teal

Financial trust beats dark-crypto theatrics. One accent (`--rf-accent`) locked across surfaces. Dark tokens exist for `prefers-color-scheme` without flipping section themes.

## Liquid glass as a layer, not a theme

Awesome Design is the full pattern library. Glass is reserved for agent, payment, and metric layers so tables stay readable.

## Playwright as a release gate

A flow is not done when it renders. Core journeys live in `e2e/`.
